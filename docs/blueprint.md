# **App Name**: Morango do Amor Pro

## Core Features:

- Recipe Presentation: Visually-driven step-by-step instructions (video, PDF) for making 'Morango do Amor Perfeito'.
- Mobile Optimization: Mobile-first design for easy access on smartphones.
- Guarantee: 7-day money-back guarantee to build trust.
- FAQ: FAQ section addressing common concerns to reduce hesitation.

## Style Guidelines:

- Primary color: Saturated pink (#F472B6) to represent the sweetness and perfection of the dessert.
- Background color: Very light pink (#FCE4EC), to give a feminine, clean and delicate feel.
- Accent color: A vivid rose color (#F00078) for the call-to-action buttons and important highlights.
- Body and headline font: 'Belleza' sans-serif for a sweet and elegant touch that resonates with the user.
- Clean and simple layout with a focus on mobile-friendliness, ensuring a smooth user experience on all devices.
- Subtle animations when scrolling through steps in the recipe, creating visual feedback and engagement.
